# 结论账本

这份账本每条结论一行，取代 README、ROADMAP、STATUS 开头不断扩写的"最新执行增量"段落。它只记录已经有保存证据支持的结论、负结果和明确的未完成项；STATUS.md 回归日志角色，不再承载结论。每条的数字和路径都在 2026-11-03 从 `legacy/`（即原仓库 /Users/fbsh/response-lab 的只读链接）逐一核对；引用文件的字节数和 SHA256 见同目录 `CONCLUSIONS.evidence.json`。

列的口径：n 是主样本数或实际运行次数，预热、smoke、参考运行不计入；性质取 已建立、负结果、未验收、待复核 四种之一。"已建立"只表示该行所写范围内的结论有证据，不表示阶段或整体目标完成。
